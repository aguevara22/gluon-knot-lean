## diagram_type

DESIGN. An oriented link diagram is a finite family of closed oriented generic polygons in `SM.Plane = ℝ × ℝ` with an over-strand choice at every double point — the printed first sentence of def:positive-lift, read in the polygonal class the SM itself uses ("A diagram here is a finite polygonal immersion", sm-3:337-341; lem:gauss-pl-model supplies PL models for the smooth case). Three layers:

(a) `structure PolyComp := (k : ℕ) (hk : 3 ≤ k) (P : LabelledTuple k)` — one component is exactly the accepted def:polygon object (`LabelledTuple k = ZMod k → Plane`), so a carrier's corner polygon is a component with no coercion.

(b) `structure Shadow := (c : ℕ) (hc : 0 < c) (comp : Fin c → PolyComp)` — c ≥ 1 is built into the type (lp:lm "Here c ≥ 1"; "Algebraic empty products are not empty links"). Derived: `Strand Γ := Σ i : Fin c, ZMod (comp i).k` (a directed edge E_j of component i), `seg/interior/dir/tail` (reusing accepted `edgeSegment`, `edgeInterior`, `edge`), `Adjacent` (same component, `adjacent a b`), `IsCrossing (x : Finset Strand) := ∃ s t, x = {s,t} ∧ ¬Adjacent s t ∧ (seg s ∩ seg t).Nonempty` — the multi-component copy of the accepted `SM.IsCrossing`, so self- and mixed crossings are one notion; `Crossing := {x // IsCrossing x}` (Fintype via `NeZero k` from `hk`), `Visit := Σ x : Crossing, {s // s ∈ x.val}` (the occurrence set M, the multi-component copy of the accepted `SM.Visit`), `crossingPoint` (Classical.choose of the common point), `Pt := Σ i, TraversalPoint (comp i).k` with `eval` (accepted `traversalEvaluation`) — the parameter circles.

(c) `structure Shadow.Generic : Prop` — "finitely many transverse double points, no triple points", polygonal immersion: `regular : ∀ i, Regular (comp i).P` (accepted def:regular: nonzero edges, no antiparallel consecutive edges; zero turns ALLOWED so subdivision vertices stay in the class), `tail_off : ∀ s t, ¬IncidentTail s t → tail s ∉ seg t` (no corner on a non-incident edge, across components; forces vertices distinct and all meetings interior), `transverse : ∀ s t, ¬Adjacent s t → (seg s ∩ seg t).Nonempty → det (dir s) (dir t) ≠ 0`, `no_triple` (no point on three edge interiors). Finiteness of double points is automatic (finitely many edge pairs, transverse segments meet at most once).

`structure Diagram := (Γ : Shadow) (generic : Γ.Generic) (overStrand : Γ.Crossing → Γ.Strand) (over_mem : ∀ x, overStrand x ∈ x.val)`. Derived operations, all total on `Diagram`: `underStrand` (the other element), `IsPositive x := 0 < det (dir (over x)) (dir (under x))` and `sign x : SignType` (def:positive-lift's convention, eq:gauss-cross-sign with u = edge vector), `writhe := ∑ x, sign x`, `switch D x₀` = D^sw (same shadow, `Function.update` of the over strand at x₀; genericity proof reused verbatim), `componentCount := Γ.c`, `IsCrossingFreeCircle := Γ.c = 1 ∧ IsEmpty Γ.Crossing`, `restrict D (B : Finset (Fin c)) (hB : B.Nonempty)` (components reindexed by `B.orderEmbOfFin`; genericity inherited; theorem: its crossings are the internal crossings — mp:stack/mp:lowest), `reverse D` (each component `reversal`-style relabelling i ↦ −i; keeps over data; cf:thm-carrierfloor (R)), `mirror D` (reflect (x,y) ↦ (x,−y), keep over data; negates every sign; the mirror paragraph of cf:thm-carrierfloor).

Based orders and basepoints (lp:lm): `structure Basing D := (rank : Fin c ≃ Fin c) (base : ∀ i, TraversalPoint (comp i).k) (nonsingular : ∀ i x, eval ⟨i, base i⟩ ≠ crossingPoint x)`. `visitPt v : Pt` (the visit's traversal point: its strand's component and the crossing parameter on that edge, strictly interior by `tail_off`), `basedRank B v : ℕ × ℝ := (rank (component of v), (traversalKey (visitPt v) − traversalKey (base i)) mod k)` and `UnderFirst D B := ∀ x, Prod.Lex (<) (<) (basedRank B (underVisit x)) (basedRank B (overVisit x))` — "traversing components in their order, from their basepoints and in their orientations, the first encounter with each crossing is the underpass". Because F, H are functions of `D` alone, "independently of the auxiliary component order, nonsingular basepoints and order of switches" is the universal quantification over `B` in the initialization clause.

Marked intervals and clean joins (mp:join, mp:blocks): a mark is `(i, I)` with `I` a closed traversal interval on component i containing no crossing point and contained in a clean disc (a closed ball meeting the diagram only in I). Following the SM's own definition ("Its finite data are precise ... The operation is not defined as an unspecified ambient isotopy class", sm-3:1370-1379), `IsMarkedJoin (A, I_A) (B, I_B) J : Prop` := `RecordIso J.record (joinRecord A.record I_A B.record I_B)` where `joinRecord` concatenates the two marked component cycles at their gaps and keeps every other component, pairing, bit and sign; c(J) = c(A)+c(B)−1 is then a theorem. Realization existence (the sphere-chart/ribbon construction of sm-3:1380-1425) is a SEPARATE lemma, not needed by mp:join's induction nor by cb:products (whose joins are the actual carriers); see fidelity risk 8 for mp:blocks.

Why polygonal: it is the accepted library's class (LabelledTuple, edge, det, Crossing, Visit, TraversalPoint are reused unchanged), positive lifts of carriers become literal `Diagram` values (section 5), signs are det-based as printed, every operation the local-polynomial block needs (switch, restriction, reversal, mirror, based orders) is a finite computation on vertex tuples, and lem:gauss-pl-model / SOURCES-INDEX §D licence the PL reading of "planar isotopy" without a sixth axiom.

## record_type

def:gauss-record is stated for one oriented circle in the sphere; the Lean type is defined for every diagram (rp:record-polynomial, lc:presentations, mp:join and prop:C-chamber need the multi-component case, "the component bijection must also include all components with no crossing occurrences") and the row's main declaration specialises to c = 1.

```
structure Record where
  comps : Type  [Fintype comps]     -- parametrizing circles, crossing-free ones included
  M : Type      [Fintype M]         -- the finite crossing-occurrence set
  comp : M → comps                  -- which circle carries the occurrence
  succ : Equiv.Perm M               -- forward successor s along the oriented circle
  pair : Equiv.Perm M               -- pairing involution τ
  isOver : M → Bool                 -- over/under bit at each occurrence
  sgn : M → SignType                -- σ(c) = sgn det(u_{c,O}, u_{c,U}), stored on both occurrences
  succ_comp : ∀ v, comp (succ v) = comp v
  succ_cycle : ∀ v w, comp v = comp w → succ.SameCycle v w   -- one cycle per circle
  pair_ne : ∀ v, pair v ≠ v          -- "without fixed points"
  pair_invol : ∀ v, pair (pair v) = v
  bit_pair : ∀ v, isOver (pair v) = !isOver v
  sgn_pair : ∀ v, sgn (pair v) = sgn v
  sgn_ne : ∀ v, sgn v ≠ 0
```
`Diagram.record D : Record` with `comps := Fin c`, `M := Γ.Visit`, `succ` = next visit along the same component's traversal (sort the visits of component i by `traversalKey (visitPt ·)` as `gaussList` does — the accepted GaussWord.lean construction lifted to a component; a component with a single visit has `succ v = v`), `pair` = the twin visit (the accepted `visitTwin` pattern), `isOver v := decide (v.2.val = overStrand v.1)`, `sgn v := D.sign v.1`. Theorem: `(record (positiveLift Q)).sgn = 1` everywhere (rem:crossing-record (a)).

```
structure RecordIso (ρ ρ' : Record) where
  e : ρ.comps ≃ ρ'.comps
  Φ : ρ.M ≃ ρ'.M
  comp_eq : ∀ v, ρ'.comp (Φ v) = e (ρ.comp v)
  succ_eq : ∀ v, Φ (ρ.succ v) = ρ'.succ (Φ v)     -- preserves successor = the oriented cyclic order of marks
  pair_eq : ∀ v, Φ (ρ.pair v) = ρ'.pair (Φ v)
  bit_eq  : ∀ v, ρ'.isOver (Φ v) = ρ.isOver v
  sgn_eq  : ∀ v, ρ'.sgn (Φ v) = ρ.sgn v
```
"A named record isomorphism is a bijection Φ : M → M' preserving successor, pairing, over/under bits and these signs ... must preserve their cyclic orders ... does not permit traversal reversal": successor preservation on an oriented circle's finite mark set is exactly cyclic-order preservation without reversal (a theorem to state for the reviewer: for ≥3 marks on one component, `succ_eq` ⇔ the induced map preserves `traversalBetween`). The definition's last sentences (the PL circle map Φ̄ extending Φ after subdivision, any positive parametrization if M is empty) become a theorem `RecordIso.extend : ∃ φ : ∀ i, TraversalPoint _ ≃ TraversalPoint _, cyclic-order preserving ∧ φ (visitPt v) = visitPt (Φ v)` proved by affine interpolation between successive marks. The row `def:gauss-record` bundles `Record`, `Diagram.record`, `RecordIso`, the sign formula and this extension theorem, specialised to c = 1.

Abstract operations on records used by the inductions: `Record.switch x` (flip the two bits), `Record.smooth x` (delete the two occurrences of x and recombine successors: (x A y B) ↦ (x B),(y A) for a self crossing, (x A),(y B) ↦ (x B y A) for a mixed one — sm-3:1085-1095), `Record.restrict`, `joinRecord`. Key bridge theorems (the heart of rp:record-polynomial and lp:core): `record (switch D x) = (record D).switch x` (definitional up to iso) and `IsOrientedSmoothing D x D₀ → RecordIso (record D₀) ((record D).smooth x)`; component count c ± 1 and crossing count N − 1 follow at the record level. F and H stay functions of the actual `Diagram`; the record is never an argument of F or H, so rp:record-polynomial remains a theorem proved by the printed (N, b) induction using lp_lm's basepoint-independent initialization and the two bridge theorems.

## ring_layer

`abbrev Laurent₂ (K) [CommRing K] := AddMonoidAlgebra K (ℤ × ℤ)` — exponent (d, k) is a^d z^k (resp. l^d m^k). `abbrev R := Laurent₂ ℤ` (= ℤ[a^{±1}, z^{±1}]); `def T := Laurent₂ ℤ` with `noncomputable instance : CommRing T := inferInstanceAs _` — a DISTINCT type so `l` can never be silently identified with `a` (the SM keeps the source ring T separate from R and forbids importing statements over R into lp:lm-uniqueness); generators `R.a = single (1,0) 1`, `R.z = single (0,1) 1`, `R.aInv = single (-1,0) 1`, `R.zInv`, `T.l, T.m, T.lInv, T.mInv`; `T.mu := -(l + lInv) * mInv`, `R.delta := (a − aInv) * zInv`. Unit laws are one-liners (`single_mul_single`, `one_def`, `Prod.mk_zero_zero`; `R.a_mul_aInv` compiled). Gaussian detour: `abbrev RG := Laurent₂ GaussianInt`, `def TG := Laurent₂ GaussianInt` (ℤ[i] = Mathlib `GaussianInt = Zsqrtd (-1)`, a CommRing, IsDomain, CharZero). Inclusion `R.toRG : R →+* RG := AddMonoidAlgebra.mapRingHom (ℤ × ℤ) (Int.castRingHom GaussianInt)`, injective by `map_injective` + `Int.cast_injective` (the "free integer basis 1, i" step). Substitutions as ring homs determined on unit generators: `unitPowers (u v : Aˣ) : Multiplicative (ℤ × ℤ) →* A`, `(p,q) ↦ u^p v^q` (proved with `zpow_add`, `ring`), then `substHom u v := AddMonoidAlgebra.lift GaussianInt A (ℤ × ℤ) (unitPowers u v)`; φ := substHom (i•a) (−i•z) : TG → RG, ψ := substHom (−i•l) (i•m) : RG → TG; `φ ∘ ψ = id` and `ψ ∘ φ = id` by `AddMonoidAlgebra.algHom_ext` on generators (lp:ring-transports). Uniqueness over T_G by coordinates: `RG ≃+ T_G ⊕ T_G`-style decomposition via `Zsqrtd.re/im` pointwise on coefficients (`mapRangeAddMonoidHom`), no division by 2.

Coefficient extraction: `coeffAt d k f : ℤ := f.coeff (d, k)` (Finsupp evaluation; "zero if that monomial is absent" is automatic) — this is `[a^d z^k]` of def:C and lem:homflyrows; `zRow k f : LaurentPolynomial ℤ` := `ofCoeff (Finsupp.comapDomain (·, k) f.coeff _)` for `[z^k]` as a ℤ[a^{±1}]-valued additive map (mp:lowest). def:adeg: `degA f : WithBot ℤ := (f.coeff.support.image Prod.fst).max`, `mindegA : WithTop ℤ := ….min`, `degZ/mindegZ` likewise on `Prod.snd`; the row states: for f ≠ 0 these are integers, the largest/smallest a-exponent with nonzero coefficient (`Finset.max'_mem`, `le_max'`), and the printed domain "Laurent polynomial in a with coefficients in the integral domain ℤ[z^{±1}]" is R itself (note recorded; the ring iso `R ≃+* LaurentPolynomial (LaurentPolynomial ℤ)` is not needed). Support subgroup of lp:support: `InSupportM c f := ∀ e ∈ f.coeff.support, 1 − c ≤ e.2 ∧ Even (e.2 − (1 − c))`, closed under +, under multiplication by a-units, and `z • M_{c+1} = M_c`, `z • M_{c−1} ⊆ M_c` (lp:self-support, lp:mixed-support). Nonvanishing (lp:core): `substHom`-style ring hom `R →+* RatFunc ℚ`, a ↦ X, z ↦ X − X⁻¹ (units of the field), sends every value to 1.

Instances for free: `IsDomain R`, `IsDomain RG` (compiled: `Prod.instUniqueSums` + `UniqueSums ℤ` via `of_covariant_right` + Mathlib's `AddMonoidAlgebra` `IsDomain` instance) — needed by def:adeg ("integral domain ℤ[z^{±1}]") and ng:circle's leading-coefficient product.

Why not the alternatives: `MvPolynomial` has ℕ exponents (no a⁻¹, z⁻¹); iterated `LaurentPolynomial (LaurentPolynomial ℤ)` makes `[a^d z^k]` two-level and the variable-mixing substitutions l ↦ ia, m ↦ −iz awkward; a bare `Finsupp (ℤ × ℤ) ℤ` has no ring structure. `AddMonoidAlgebra ℤ (ℤ × ℤ)` is literally Mathlib's own `LaurentPolynomial` construction (`AddMonoidAlgebra R ℤ`) with a second exponent, so its one-variable API (`single_mul_single`, `lift`, `mapRingHom`, `degree`) is the template for every lemma we need; in this Mathlib `AddMonoidAlgebra` is a structure with field `coeff : M →₀ R`, so all coefficient statements are `Finsupp` statements.

## skein_and_moves

One primitive carries planar isotopy, the three moves and the oriented smoothing, so that all three axioms quantify over the same objects and reversal/mirror lemmas are proved once.

Reparametrization (same trace, subdivision, relabelling, component reindexing): `Reparam D D' := ∃ (e : Fin c ≃ Fin c') (φ : ∀ i, TraversalPoint (comp i).k ≃ TraversalPoint (comp' (e i)).k), (∀ i p q r, traversalBetween p q r → traversalBetween (φ i p) (φ i q) (φ i r)) ∧ (∀ i p, eval' ⟨e i, φ i p⟩ = eval ⟨i, p⟩) ∧ (∀ x, ∃ x', ⟨e _, φ _ (visitPt (overVisit x)).2⟩ = visitPt' (overVisit' x'))` (accepted `traversalBetween`; the last clause transports the over data as traversal points, not as evaluated points).

Generic deformation: `Deform D D' := ∃ γ : ℝ → (∀ i, LabelledTuple (comp i).k)`, continuous on [0,1] (each vertex a continuous path), `γ 0 = D.comp`, `γ 1 = D'.comp` (same `c`, same `k`), every intermediate shadow `Generic`, the crossing set (as `Finset (Finset Strand)`) constant along the path, and `D'.overStrand = D.overStrand` under that identification (constancy of crossings along generic paths is a theorem — prop:chambers' multi-component analogue — but requiring it in the definition is harmless and avoids proving it before stating the axioms).

`PlanarIsotopic := Relation.EqvGen (Reparam ∨ Deform)` — positive page isotopy in the PL class of lem:gauss-pl-model; every generator is realized by an orientation-preserving ambient PL isotopy and conversely PL isotopies factor through these, so the relation is faithful up to the PL/topological identification the SM itself makes.

Local replacement primitive: `AgreeOutside (B : Set Plane) D D' : Prop` := there are `e`, `φ` as in `Reparam` such that `eval' (φ p) = eval p` whenever `eval p ∉ interior B`, crossings with point outside `interior B` correspond under φ with the same over visit, and `D ∩ B`, `D' ∩ B` are described by their arcs: the traversal points evaluating into B form finitely many closed traversal intervals ("arcs") whose endpoints are exactly the points on ∂B (no vertex on ∂B, each arc meets ∂B only at its two ends), with φ matching arcs end to end. Patterns are then counting conditions on the arcs inside B (each arc embedded, listed crossings the only meetings):
- `RI D D'`: one arc in B on each side; D's arc crossing-free, D''s arc with exactly one self-crossing (a kink), either sign;
- `RII D D'`: two arcs on each side, same endpoint pairing and directions; D's arcs disjoint, D''s arcs crossing exactly twice with the SAME over strand at both crossings;
- `RIII D D'`: three arcs on each side, pairwise crossing exactly once (a triangle) on both sides, the same over/under relation on each of the three pairs (one strict height order), and the order of the two visits along every arc reversed. These are the standard characterizations of the three tangles in a disc (an embedded arc with one self-crossing is a kink; two embedded arcs with non-alternating endpoints and two crossings bound a bigon; three pairwise-crossing chords admit exactly two configurations, exchanged by reversing the visit orders), and they are exactly the "actual ordinary oriented Reidemeister moves" the SM performs on concrete polygonal diagrams (cf:lem-curl's monogon deletion at sm-3:4259-4267, ng:front-I/II/III roundings).
- `IsOrientedSmoothing D x D₀ := ∃ B` a closed ball about `crossingPoint x` with `AgreeOutside B D D₀`, D ∩ B = the two strands' subsegments through x and nothing else, D₀ ∩ B = two disjoint embedded crossing-free arcs joining each incoming end to the OTHER outgoing end ("Oriented smoothing reconnects each incoming strand to the other strand's outgoing end. It removes just the selected crossing and creates no other crossing in its clean disc", sm-3:1084-1086).
- `IsSkeinTriple D₊ D₋ D₀ := ∃ x, D₊.IsPositive x ∧ D₋ = D₊.switch x ∧ IsOrientedSmoothing D₊ x D₀` (D₋ is literally the switch, which is all LM's and the SM's inductions ever use; see fidelity risk 3).
- `LinkEquiv := Relation.EqvGen (PlanarIsotopic ∨ RI ∨ RII ∨ RIII)`.

Theorems (not axioms) the consumers need on top of the definitions: `exists_smoothing : ∀ D x, ∃ D₀, IsOrientedSmoothing D x D₀` (cut both edges at distance ε before and after the crossing point, join crosswise; genericity for small ε by finiteness/openness — the geometric heart of lp:core, sm-3:1084-1103), `smoothing_record : IsOrientedSmoothing D x D₀ → RecordIso D₀.record (D.record.smooth x)` (hence c(D₀) = c ± 1 ≥ 1 and N − 1 crossings), `switch_record`, `smoothing_of_restrict` (mp:stack), `reverse`/`mirror` carry `Reparam`, `Deform`, `RI/RII/RIII`, `IsSkeinTriple` to themselves (cf:thm-carrierfloor (R) and mirror paragraph), and the sanity counts (RI changes the crossing number by ±1, RII by ±2, RIII by 0; component counts preserved), which are the reviewers' checks that the move patterns are the printed ones.
