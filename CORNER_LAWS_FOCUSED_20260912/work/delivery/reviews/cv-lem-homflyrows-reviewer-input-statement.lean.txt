## The printed statement (d6_vertexedge.tex:119–139)

"Put R = ℤ[a^{±1}, z^{±1}] and δ = (a − a⁻¹)/z ∈ R.
(i) For oriented knots K, J, P_{K#J} = P_K P_J; and for an oriented knot K and an oriented link J,
    P_{K⊔J} = δ P_K P_J.
(ii) Let D be an oriented link diagram with ordered components D₁, D₂ and linking number λ.  Then
    [z^{−1}] P_D = (a − a⁻¹) a^{−2λ} [z^0](P_{D₁} P_{D₂}).
(iii) Consequently, for oriented knots K₁, …, Kₙ (n ≥ 1), P_{K₁ ⊔ ⋯ ⊔ Kₙ} = δ^{n−1} P_{K₁} ⋯ P_{Kₙ}."

## Notation map (printed → Lean; everything lives in `SM.Link` unless said otherwise)

* "R = ℤ[a^{±1}, z^{±1}]": `R` (SM/LinkLaurentRing.lean:76) with `R.a`, `R.aInv`, `R.z`, `R.zInv`.
  "δ = (a − a⁻¹)/z ∈ R": `R.delta = (R.a − R.aInv) * R.zInv` (SM/LinkLaurentRing.lean:193; division by
  the unit z is multiplication by `R.zInv`; `CV.delta_eq`, `CV.delta_mul_z` record "δ · z = a − a⁻¹").
  This is the δ of the accepted CV:def:homfly row (`CV.homfly_definition.split_circle` writes it out
  as `(R.a − R.aInv) * R.zInv`).
* "oriented knot K": a one-component polygonal oriented link diagram `K : Diagram`
  (`K.componentCount = 1`) standing for its `LinkEquiv` class (SM/LinkMoves.lean:760 — the relation
  generated by planar isotopy and the three Reidemeister moves; design decision D2 of the SM library:
  Reidemeister's theorem is outside the formal scope, so "isotopy class of an oriented link" is read
  as `LinkEquiv` class throughout, exactly as in CV:ax:homfly).  "P_K" is `homfly K`, well defined on
  the class by `homfly_descent`.  "oriented link J": any `J : Diagram`, any component count.
* "K # J" for oriented knots (122–124): any clean marked join `D` of marked representatives
  `K' ~ K`, `J' ~ J` — `IsCleanMarkedJoin K' J' D` (SM/MarkedProducts.lean:95: an actual diagram whose
  named record is the record-level marked join `Record.joinRecord K'.μ J'.μ`), with
  `K' J' : MarkedDiagram` (a diagram with a specified crossing-free interval in a clean disc,
  SM/MarkedProducts.lean:75).  This is SM lem:homflyrows' reading and it is also what CV's proof
  constructs (149–152: "K #_p J is made in a ball at p … by deleting a short oriented arc through p,
  cutting a copy of K at a short oriented arc, and using the orientation-compatible cross-pairing" —
  the two marked intervals are the two short arcs).  The well-definedness of "K # J" as an operation
  on knot classes is not claimed (design decision D9); the row asserts the identity for every clean

* "K ⊔ J" (126–128), "put K in a ball disjoint from J" (207): `IsSplitUnion K' J' D`
  (SM/MarkedProducts.lean:276) for representatives `K' ~ K`, `J' ~ J`: `D` is partitioned into two
  nonempty component blocks with no crossing between the blocks, and the two block restrictions have

## Design decisions recorded

(a) Every reading above is SM lem:homflyrows' reading (knots = `LinkEquiv` classes of one-component

    λ through `mixedSignSum`); CV's text differs from SM's only in (1) stating the split identity for a
    knot and a LINK, (2) naming the linking number λ instead of lk, and (3) adding clause (iii).
(b) The knot ⊔ link clause is `SM.Link.P_splitUnion` (SM/MarkedProducts.lean:4899), which is stated
    for ANY two diagrams `K' J'` (no component-count hypothesis) — mp:stack with two blocks and no mixed
    crossing — transported along lp:core's `P = homfly` (`SM.P_eq_homfly`) and lit:homfly's descent.
    No new lemma is needed; CV's based relative-uniqueness argument (154–219) is replaced by the
    library's route, as SM's proof already does.
(c) CV's (ii) is literally SM's `two_component_row` once `2 * ℓ` is substituted for `twoLinking D i j`:
    same coefficient `(a − a⁻¹) a^{−2λ}` in the same order, same `[z^0]` of the PRODUCT (SM's proof
    turns mp:lowest's product of `[z^0]` rows into the `[z^0]` of the product through

    `CV.two_component_row_rows` for the R-lane consumers who read (ii) "together with the knot-parity
    clause of CV:ax:homfly").
(d) Fidelity: see the report work/drafts/cvdom/CVHOMFLYROWS_REPORT.md.  In short: `LinkEquiv` for
    isotopy (D2); marked joins for `#` and the unclaimed well-definedness (D9); the polygonal split
    reading of `⊔`; the printed one-component hypotheses are kept although the identities hold for
    all links; (iii) as an n-block split diagram with the printed parenthesization supplementary. -/

/-! ## "Put R = ℤ[a^{±1}, z^{±1}] and δ = (a − a⁻¹)/z ∈ R" (d6_vertexedge.tex:119–120) -/

/-- "δ = (a − a⁻¹)/z": the library's `R.delta` is `(a − a⁻¹) · z⁻¹` by definition. -/
theorem delta_eq : R.delta = (R.a - R.aInv) * R.zInv := rfl

/-- "δ = (a − a⁻¹)/z" read as a division: `δ · z = a − a⁻¹` (`R.delta_mul_z`). -/
theorem delta_mul_z : R.delta * R.z = R.a - R.aInv := R.delta_mul_z

/-! ## "linking number λ" (d6_vertexedge.tex:131) -/

/-- "linking number λ" of the ordered components `i, j` of the diagram `D`: `2λ` is the sum of the
decorated signs over all mixed crossings between the two components (`mixedSignSum`, mp:zero-link);
this is the convention of the printed proof ("λ₊ = λ₋ + 1 at a positive versus negative mixed
crossing", 235–236).  SM lem:homflyrows writes the same quantity as `twoLinking D i j = 2·lk`. -/
def IsLinkingNumber (D : Diagram) (i j : Fin D.Γ.c) (ℓ : ℤ) : Prop :=
  2 * ℓ = mixedSignSum D i j

/-- Two distinct components have a linking number: the mixed sign sum is even (mp:zero-link,
`SM.zero_link.half_sum_integer`). -/
theorem exists_linkingNumber (D : Diagram) (i j : Fin D.Γ.c) (hij : i ≠ j) :
    ∃ ℓ : ℤ, IsLinkingNumber D i j ℓ := by
  obtain ⟨k, hk⟩ := SM.zero_link.half_sum_integer D i j hij
  exact ⟨k, hk.symm⟩

/-- The linking number is unique. -/
theorem IsLinkingNumber.unique {D : Diagram} {i j : Fin D.Γ.c} {ℓ ℓ' : ℤ}
    (h : IsLinkingNumber D i j ℓ) (h' : IsLinkingNumber D i j ℓ') : ℓ = ℓ' := by
  unfold IsLinkingNumber at h h'
  omega

/-- The factor-2 bookkeeping against SM lem:homflyrows: `twoLinking D i j = 2λ`. -/
theorem IsLinkingNumber.twoLinking_eq {D : Diagram} {i j : Fin D.Γ.c} {ℓ : ℤ}
    (h : IsLinkingNumber D i j ℓ) : twoLinking D i j = 2 * ℓ := by
  unfold twoLinking
  exact h.symm

/-! ## "K ⊔ J" for a knot and a link (d6_vertexedge.tex:126–128, proof 207–220) -/

/-- The split identity for any two diagrams, on representatives: `P_{K'⊔J'} = δ P_{K'} P_{J'}`
(`SM.Link.P_splitUnion`, mp:stack with two blocks and no mixed crossing) transported to the classes
of `K`, `J` along `P = homfly` (lp:core) and lit:homfly's descent.  No hypothesis on component counts:
this is the "knot K and link J" clause and more. -/
theorem homfly_splitUnion (K J K' J' D : Diagram) (hK : LinkEquiv K K') (hJ : LinkEquiv J J')
    (h : IsSplitUnion K' J' D) : homfly D = R.delta * (homfly K * homfly J) := by
  rw [← P_eq_homfly, Link.P_splitUnion K' J' D h, P_eq_homfly, P_eq_homfly, homfly_descent hK,
    homfly_descent hJ]

/-! ## "K₁ ⊔ ⋯ ⊔ Kₙ" (d6_vertexedge.tex:136–138) -/

/-- "K₁ ⊔ ⋯ ⊔ Kₙ", the split union of `n` diagrams: `D` is partitioned into `n` component blocks
(the fibres of a surjection `blk` onto `Fin n`) with no crossing between distinct blocks, and block
`i` has the named record of `K i` (`blockRestrict`, mp:stack's block restriction).  This is
`IsSplitUnion` with `n` blocks instead of two (`isSplitUnionFamily_of_isSplitUnion`). -/
def IsSplitUnionFamily {n : ℕ} (K : Fin n → Diagram) (D : Diagram) : Prop :=
  ∃ (blk : Fin D.Γ.c → Fin n) (hblk : Function.Surjective blk),
    (∀ (x : D.Γ.Crossing), ∀ s ∈ x.val, ∀ t ∈ x.val, blk s.1 = blk t.1) ∧
    ∀ i : Fin n, Nonempty (RecordIso (blockRestrict D blk hblk i).record (K i).record)

/-- Sanity: the two-block split union of (i) is the `n = 2` case. -/
theorem isSplitUnionFamily_of_isSplitUnion {K J D : Diagram} (h : IsSplitUnion K J D) :
    IsSplitUnionFamily ![K, J] D := by
  obtain ⟨B, hB, hB', hno, hK, hJ⟩ := h
  let blk : Fin D.Γ.c → Fin 2 := fun c => if c ∈ B then 0 else 1
  have hsurj : Function.Surjective blk := by
    intro k
    fin_cases k
    · obtain ⟨c, hc⟩ := hB
      exact ⟨c, by simp [blk, hc]⟩
    · obtain ⟨c, hc⟩ := hB'
      exact ⟨c, by simp [blk, Finset.mem_compl.mp hc]⟩
  refine ⟨blk, hsurj, ?_, ?_⟩
  · intro x s hs t ht
    have hiff := hno x s hs t ht
    simp only [blk]
    by_cases hsB : s.1 ∈ B
    · rw [ite_eq_left hsB, ite_eq_left (hiff.mp hsB)]
    · rw [ite_eq_right hsB, ite_eq_right (fun h => hsB (hiff.mpr h))]
  · intro i
    fin_cases i
    · have e : blockRestrict D blk hsurj 0 = D.restrict B hB := by
        unfold blockRestrict
        apply D.restrict_congr
        ext c
        by_cases hc : c ∈ B <;> simp [blk, hc]
      simpa [e] using hK
    · have e : blockRestrict D blk hsurj 1 = D.restrict Bᶜ hB' := by
        unfold blockRestrict
        apply D.restrict_congr
        ext c
        by_cases hc : c ∈ B <;> simp [blk, hc]
      simpa [e] using hJ

/-- mp:stack with `n` blocks and no mixed crossing: `P_D = δ^{n−1} ∏ P_{K i}` on representatives
(`SM.stack_formula`; "no crossing between blocks" makes `BlockOrdered` vacuous, and lc:presentations
identifies each block restriction with `K i`). -/
theorem P_splitUnionFamily {n : ℕ} (K : Fin n → Diagram) (D : Diagram)
    (h : IsSplitUnionFamily K D) : P D = R.delta ^ (n - 1) * ∏ i, P (K i) := by
  obtain ⟨blk, hblk, hno, hiso⟩ := h
  have hbo : BlockOrdered D blk := fun x s t hs ht hlt => by
    rw [hno x s hs t ht] at hlt
    exact absurd hlt (lt_irrefl _)
  rw [stack_formula D n blk hblk hbo]
  congr 1
  exact Finset.prod_congr rfl fun i _ => presentations _ _ (hiso i)

/-- Clause (iii) on classes: for representatives `K' i ~ K i` and any split union `D` of the `K' i`,
`homfly D = δ^{n−1} ∏ homfly (K i)`. -/
theorem homfly_splitUnionFamily {n : ℕ} (K K' : Fin n → Diagram) (D : Diagram)
    (hK : ∀ i, LinkEquiv (K i) (K' i)) (h : IsSplitUnionFamily K' D) :
    homfly D = R.delta ^ (n - 1) * ∏ i, homfly (K i) := by
  rw [← P_eq_homfly, P_splitUnionFamily K' D h]
  congr 1
  exact Finset.prod_congr rfl fun i _ => by rw [P_eq_homfly, homfly_descent (hK i)]

/-! ## Row 157 — CV:lem:homflyrows (d6_vertexedge.tex:117–141) -/

/-- The printed clauses of CV:lem:homflyrows (d6_vertexedge.tex:119–139), one field per printed
display, for the HOMFLY–PT polynomial `homfly : Diagram → R` (CV's `P`, by CV:ax:homfly and

  /-- (iii) (136–139): "Consequently, for oriented knots K₁, …, Kₙ (n ≥ 1),
  P_{K₁ ⊔ ⋯ ⊔ Kₙ} = δ^{n−1} P_{K₁} ⋯ P_{Kₙ}" — for one-component diagrams `K i`, representatives

/-! ## Supplementary forms (not printed clauses) -/

/-- (ii) with the `[z^0]` of the product split into the product of the `[z^0]` rows — the form
mp:lowest produces and the form the R-lane consumers read (plan §157 (2): "(ii) … together with the
knot-parity clause of CV:ax:homfly").  From `homflyrows.two_component_row` and CV:ax:homfly's

theorem two_component_row_rows (D : Diagram) (i j : Fin D.Γ.c) (h2 : D.componentCount = 2)
    (hij : i ≠ j) (ℓ : ℤ) (hℓ : IsLinkingNumber D i j ℓ) :
    zRow (-1) (homfly D) =
      (aPow 1 - aPow (-1)) * aPow (-(2 * ℓ)) *
        (zRow 0 (homfly (D.knotRestrict i)) * zRow 0 (homfly (D.knotRestrict j))) := by
  rw [CV.homflyrows.two_component_row D i j h2 hij ℓ hℓ,
    ax_homfly.knot_product_z0 _ _
      (ax_homfly.knot_parity _ (Diagram.knotRestrict_componentCount D i))
      (ax_homfly.knot_parity _ (Diagram.knotRestrict_componentCount D j))]

/-- The printed proof's parenthesization of (iii) (d6_vertexedge.tex:220–224: "Clause (iii) follows by
induction on n: the case n = 1 is trivial, and K₁ ⊔ (K₂ ⊔ ⋯ ⊔ Kₙ) applies (i)'s split identity with
knot K₁ and link K₂ ⊔ ⋯ ⊔ Kₙ"): `IsSplitChain n K D` says `D` presents `K₁ ⊔ (K₂ ⊔ (⋯ ⊔ K_{n+1}))` —
for `n = 0`, `D ~ K₁`; for `n + 1`, `D` is a split union of a representative of `K₁` and a chain
diagram of the remaining knots. -/
def IsSplitChain : (n : ℕ) → (Fin (n + 1) → Diagram) → Diagram → Prop
  | 0, K, D => LinkEquiv (K 0) D
  | n + 1, K, D => ∃ K₁ D' : Diagram,
      LinkEquiv (K 0) K₁ ∧ IsSplitChain n (Fin.tail K) D' ∧ IsSplitUnion K₁ D' D

/-- (iii) along the printed induction: `homfly D = δ^n ∏_{i : Fin (n+1)} homfly (K i)` for a chain
diagram of `K₁ ⊔ (K₂ ⊔ ⋯ ⊔ K_{n+1})`.  Induction on `n`; the step is `homfly_splitUnion` (clause (i)'s
split identity) with knot `K₁` and link `K₂ ⊔ ⋯ ⊔ K_{n+1}`. -/
theorem homfly_splitChain : ∀ (n : ℕ) (K : Fin (n + 1) → Diagram) (D : Diagram),
    IsSplitChain n K D → homfly D = R.delta ^ n * ∏ i, homfly (K i)
  | 0, K, D, h => by
    simp only [IsSplitChain] at h
    rw [homfly_descent h.symm, pow_zero, one_mul, Fin.prod_univ_one]
  | n + 1, K, D, h => by
    obtain ⟨K₁, D', hK₁, hD', hsplit⟩ := h
    have e : ∏ i, homfly (K i) = homfly (K 0) * ∏ i, homfly (Fin.tail K i) := by
      rw [Fin.prod_univ_succ]
      rfl
    rw [homfly_splitUnion (K 0) D' K₁ D' D hK₁ (LinkEquiv.refl D') hsplit,
      homfly_splitChain n (Fin.tail K) D' hD', e, pow_succ]
    ring

end CV
