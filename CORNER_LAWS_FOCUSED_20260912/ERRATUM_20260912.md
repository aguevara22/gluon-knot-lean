## 1. Confirmed erratum — `lem:shift`(iii), `SM/sm-1-polygons.tex:495–496`

Printed: "hence ℓ(P̄) = n − ℓ(P)". False when P has a zero turn. Definitions in force: τ_i(P) = χ_{i−1,i,i+1}(P) ∈ {−1, 0, 1} and ℓ(P) = #{i : τ_i(P) = 1} for every labelled tuple (`def:chirotope`, sm-1:63–69); the lemma states no hypothesis. Since τ_i(P̄) = −τ_{2−i}(P) (the clause's first part, proved as printed), the left turns of P̄ are the right turns of P, so

    ℓ(P̄) = n − ℓ(P) − z(P),   z(P) = #{i : τ_i(P) = 0},

and ℓ(P̄) = n − ℓ(P) holds exactly when z(P) = 0, in particular on the generic locus 𝒰_n (every turn is ±1 by `lem:g1`(ii)). Witness: P = ((0,0), (1,0), (2,0), (1,1)), turns (1, 0, 1, 1), ℓ(P) = 3, z(P) = 1; P̄ has turns (−1, 0, −1, −1), ℓ(P̄) = 0; printed value 1. Both consumers of the clause (sm-4:1143, sm-5:61) apply it on 𝒰_n; nothing downstream changes. Formalize the corrected identity as stated above; the source frame is repaired in a successor frame (SM13) and the Lean statement then realigns. Recorded as finding F-25-189.
